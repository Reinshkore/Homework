# 本地网页调用阿里云百炼智能体 —— 学习与构建指南

> 用途：作为课程作业的前置研究文档。回答三个问题：**要重点学什么**、**示例会如何被构建**、**要跑起来还需要做什么准备**。
> 调研依据：[阿里云百炼官方文档](https://docs.bailian.console.aliyun.com/zh/model-studio/)（下文均标注出处链接）。
> 调研日期：2026-09-29。

---

## 0. 结论速览（先看这一段）

- **推荐架构：本地网页（前端）→ 本地代理服务（Node.js）→ 百炼应用 API**。
  - 网页不直接调用百炼，而是请求本机的 `http://localhost:3000/api/chat`，由本地服务携带 API Key 转发到百炼。
- **为什么不能"网页直连百炼"**（这是本作业最容易踩的坑）：
  1. **跨域（CORS）**：浏览器有同源策略，网页直连 `dashscope.aliyuncs.com` 会因对方未开放跨域响应头而被浏览器拦截（社区大量实践均如此，官方文档也**从未承诺**支持浏览器直连）；
  2. **密钥泄露**：网页源码中的 `sk-` 开头的 API Key 对任何打开页面的人都是可见的。官方明确将浏览器/移动端归为"不受信环境"，建议由后端签发[临时 API Key](https://help.aliyun.com/zh/model-studio/generate-temporary-api-key)再给前端使用。
- **核心调用只有一个接口**（智能体/工作流通用）：
  
  ```
  POST https://dashscope.aliyuncs.com/api/v1/apps/{APP_ID}/completion
  Authorization: Bearer sk-xxxxxx
  ```

- 示例本身很小（两个文件、零依赖、Node 18+ 直接运行），**真正的门槛在于账号侧的准备工作**（见第 4 节清单）。

## 1. 需要重点学习的知识点

### 1.1 百炼平台侧（核心，必学）

| 优先级 | 知识点 | 要搞清楚什么 | 参考文档 |
|---|---|---|---|
| ★★★ | 应用类型与版本 | 百炼有三种应用：智能体（Agent）、工作流（Workflow）、高代码应用。智能体又分 **Agent 1.0（旧版）** 与 **Agent 2.0（新版，官方推荐）**，两者的调用接口相同但能力/透明度不同 | [应用类型介绍](https://help.aliyun.com/zh/model-studio/application-introduction) |
| ★★★ | 创建并配置智能体 | 在"应用管理"创建应用 → 选模型 → 写系统提示词 →（可选）挂知识库/MCP 工具 → 调试 | [新版智能体应用（Agent 2.0）](https://help.aliyun.com/zh/model-studio/new-single-agent-application) |
| ★★★ | **发布机制** | **`APP_ID` 永远指向"最新已发布版本"**；控制台改了配置不发布，API 调用仍是旧行为。发布 → 应用卡片 → API 调试，是官方给的排错路径 | [DashScope API 参考](https://help.aliyun.com/zh/model-studio/agent-and-workflow-application-api-reference) |
| ★★★ | 应用调用 API | 端点、请求头、请求体（`input` / `parameters`）、响应体（`output.text` 等）——见本文第 2 节，是整份文档的核心 | [调用智能体应用](https://help.aliyun.com/zh/model-studio/call-single-agent-application) |
| ★★☆ | API Key 管理 | 在[密钥管理](https://bailian.console.aliyun.com/?tab=model#/api-key)创建；**Key 与地域绑定**（用北京的 Key 调其他地域端点会返回 401 `invalid_api_key`）；建议配置到环境变量而非硬编码 | [获取与配置 API Key](https://help.aliyun.com/zh/model-studio/get-api-key) |
| ★★☆ | 多轮对话 | 两种方式二选一：① `session_id`（云端托管历史，**连续 1 小时无请求即失效**）；② 自己维护 `messages` 数组回传（**优先于** `session_id`） | [调用智能体应用·多轮对话](https://help.aliyun.com/zh/model-studio/call-single-agent-application) |
| ★★☆ | 流式输出（SSE） | HTTP 调用时在**请求头**加 `X-DashScope-SSE: enable`，并在 `parameters` 里设 `incremental_output: true`，响应变为逐块返回 | 同上 |
| ★☆☆ | Responses API（OpenAI 兼容） | 若希望复用 OpenAI 风格代码：`POST https://dashscope.aliyuncs.com/api/v2/apps/agent/{APP_ID}/compatible-mode/v1/responses` | [同步调用 API 参考](https://help.aliyun.com/zh/model-studio/synchronous-call-api-reference) |
| ★☆☆ | 子业务空间 | 只有调用**子业务空间**的应用时，才需要在请求头带 `X-DashScope-WorkSpace` | [DashScope API 参考](https://help.aliyun.com/zh/model-studio/agent-and-workflow-application-api-reference) |

### 1.2 Web 侧（掌握概念即可，写代码不难）

| 知识点 | 要搞清楚什么 |
|---|---|
| `fetch` 与 HTTP 基础 | 如何发 POST JSON、如何读响应状态码与 JSON |
| 同源策略与 CORS | "协议+域名+端口"任一不同即跨域；跨域由**浏览器**拦截，服务器之间不存在此限制——这是"本地代理"方案成立的原理 |
| 预检请求（OPTIONS） | 带自定义头（如 `Authorization`）的跨域请求会先发 OPTIONS 预检，对方不放行则直接失败 |
| SSE（Server-Sent Events） | 流式输出的传输格式（`text/event-stream`），前端可用 `fetch` + `ReadableStream` 或 `EventSource` 逐字渲染 |
| 本地代理 / 开发服务器代理 | Vite、Webpack Dev Server 的 `proxy`，以及本示例手写的 Node 代理，本质相同 |
| 环境变量与密钥管理 | 密钥放服务端环境变量；确认 `.gitignore`，避免把密钥提交进 Git 仓库 |

### 1.3 安全侧（课程常考的"为什么"）

- **前端永远不放永久 API Key**：一旦放进 HTML/JS，等价于公开。
- **临时 API Key 机制**（本作业可作进阶加分项）：
  
  ```
  POST https://dashscope.aliyuncs.com/api/v1/tokens?expire_in_seconds=1800
  Authorization: Bearer <永久API Key>
  → 返回 {"token":"st-****","expires_at":...}
  ```
  
  默认有效期 60 秒，可设 1~1800 秒；用于"后端签发、前端短时使用"的场景。详见[临时 API Key 文档](https://help.aliyun.com/zh/model-studio/generate-temporary-api-key)。

## 2. 核心接口备忘（从官方文档摘录，构建时直接照抄）

### 2.1 请求

```bash
curl -X POST https://dashscope.aliyuncs.com/api/v1/apps/APP_ID/completion \
--header "Authorization: Bearer $DASHSCOPE_API_KEY" \
--header 'Content-Type: application/json' \
--data '{
  "input": {
    "prompt": "你是谁？"
  },
  "parameters": {},
  "debug": {}
}'
```

请求体字段（HTTP 调用时的归属）：

| 字段 | 位置 | 说明 |
|---|---|---|
| `prompt` | `input` | 用户输入（必填） |
| `session_id` | `input` | 多轮会话 ID；与 `prompt` 搭配，云端自动带历史 |
| `messages` | `input` | `[{role, content}]` 自管历史；与 `session_id` 同时传时**以 messages 为准** |
| `incremental_output` | `parameters` | 流式时增量返回，推荐 `true` |
| `has_thoughts` | `parameters` | 输出思考/工具调用过程（配合 `enable_thinking`） |
| `enable_thinking` | `parameters` | 切换深度思考模型的思考模式 |
| `enable_web_search` | `parameters` | 是否使用联网搜索（会额外消耗 Token） |
| `model_id` | `parameters` | 临时指定模型（覆盖控制台配置） |
| 流式开关 | **请求头** | `X-DashScope-SSE: enable` |

### 2.2 响应（非流式）

```json
{
  "output": {
    "finish_reason": "stop",
    "session_id": "232ea2e9e6ef448db6b14465c06a9a56",
    "text": "……智能体的回答……"
  },
  "usage": { "models": [ { "input_tokens": 121, "output_tokens": 51, "model_id": "qwen-max" } ] },
  "request_id": "661c9cad-e59c-9f78-a262-78eff243f151"
}
```

> 排错关键：出错时记住 `request_id`，配合[错误码文档](https://help.aliyun.com/zh/model-studio/developer-reference/error-code)定位。

## 3. 示例如何被构建

### 3.1 架构

```
┌──────────────────┐        ┌───────────────────────┐        ┌──────────────────────────┐
│  浏览器（本地网页） │  POST  │  本地代理服务 (Node)    │  POST  │  阿里云百炼               │
│  index.html      │ ─────► │  server.mjs           │ ─────► │  /api/v1/apps/{APP_ID}   │
│  fetch /api/chat │        │  持有 API Key（服务端）  │        │  /completion             │
│  渲染回答         │ ◄───── │  转发并回传 JSON        │ ◄───── │  （智能体应用）           │
└──────────────────┘        └───────────────────────┘        └──────────────────────────┘
     同源，无跨域                密钥只存在于这里              返回 output.text / session_id
```

一次提问的完整数据流：

1. 网页把用户输入 `fetch` 到本机 `/api/chat`（同源，无跨域问题）；
2. 本地服务读取环境变量里的 `DASHSCOPE_API_KEY` 和 `BAILIAN_APP_ID`，向百炼发起 HTTPS 请求；
3. 百炼返回 JSON；本地服务原样回传给网页；
4. 网页把 `output.text` 渲染出来，并把 `output.session_id` 存下来用于下一轮多轮对话。

### 3.2 文件结构（3 个文件即可）

```
20260929/
├── server.mjs            # 本地代理服务（零依赖，Node 18+ 内置 fetch）
└── public/
    └── index.html        # 前端页面（纯 HTML/JS，无需框架）
```

### 3.3 `server.mjs`（完整最小实现）

```js
// 本地代理服务：零依赖，Node 18+ 直接运行
// 运行前设置环境变量（不要写死在代码里）：
//   $env:DASHSCOPE_API_KEY = "sk-xxxxxx"
//   $env:BAILIAN_APP_ID    = "你的应用ID"
import http from 'node:http';
import { readFile } from 'node:fs/promises';

const API_KEY = process.env.DASHSCOPE_API_KEY;
const APP_ID  = process.env.BAILIAN_APP_ID;
const PORT    = 3000;

if (!API_KEY || !APP_ID) {
  console.error('请先设置环境变量 DASHSCOPE_API_KEY 和 BAILIAN_APP_ID');
  process.exit(1);
}

const server = http.createServer(async (req, res) => {
  // 1) 提供静态页面
  if (req.method === 'GET' && (req.url === '/' || req.url === '/index.html')) {
    const html = await readFile(new URL('./public/index.html', import.meta.url));
    res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' });
    return res.end(html);
  }

  // 2) 代理：网页 -> 百炼智能体
  if (req.method === 'POST' && req.url === '/api/chat') {
    try {
      let body = '';
      for await (const chunk of req) body += chunk;
      const { prompt, session_id } = JSON.parse(body || '{}');

      const upstream = await fetch(
        `https://dashscope.aliyuncs.com/api/v1/apps/${APP_ID}/completion`,
        {
          method: 'POST',
          headers: {
            'Authorization': `Bearer ${API_KEY}`,
            'Content-Type': 'application/json',
          },
          body: JSON.stringify({
            input: { prompt, ...(session_id ? { session_id } : {}) },
            parameters: {},   // 流式输出时改为 { incremental_output: true } 并加 SSE 请求头
            debug: {},
          }),
        }
      );

      const data = await upstream.json();
      res.writeHead(upstream.status, { 'Content-Type': 'application/json; charset=utf-8' });
      res.end(JSON.stringify(data));
    } catch (err) {
      res.writeHead(500, { 'Content-Type': 'application/json; charset=utf-8' });
      res.end(JSON.stringify({ message: String(err) }));
    }
    return;
  }

  res.writeHead(404);
  res.end('Not Found');
});

server.listen(PORT, () => console.log(`已启动：http://localhost:${PORT}`));
```

### 3.4 `public/index.html`（完整最小实现）

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8" />
  <title>百炼智能体本地网页 Demo</title>
  <style>
    body { font-family: system-ui, sans-serif; max-width: 720px; margin: 40px auto; }
    #out { white-space: pre-wrap; background: #f5f5f5; padding: 12px; min-height: 160px; }
    input { width: 70%; padding: 8px; }
    button { padding: 8px 16px; }
  </style>
</head>
<body>
  <h1>百炼智能体问答</h1>
  <input id="q" placeholder="输入你的问题，回车发送" />
  <button id="send">发送</button>
  <pre id="out"></pre>

  <script>
    let sessionId = null; // 多轮对话：首次响应会返回 session_id，后续带上即可
    const out = document.getElementById('out');
    const input = document.getElementById('q');

    async function ask() {
      const prompt = input.value.trim();
      if (!prompt) return;
      input.value = '';
      out.textContent += `\n我：${prompt}\n智能体：`;

      try {
        const resp = await fetch('/api/chat', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ prompt, session_id: sessionId }),
        });
        const data = await resp.json();

        if (!resp.ok) {
          out.textContent += `[请求失败 ${resp.status}] ${data.message || ''}\n`;
          return;
        }
        sessionId = data.output.session_id;   // 记住会话，实现多轮
        out.textContent += `${data.output.text}\n`;
      } catch (err) {
        out.textContent += `[本地服务异常] ${err}\n`;
      }
    }

    document.getElementById('send').onclick = ask;
    input.addEventListener('keydown', (e) => { if (e.key === 'Enter') ask(); });
  </script>
</body>
</html>
```

### 3.6 进阶扩展（按需，不必一次做完）

| 扩展 | 改动点 |
|---|---|
| **流式逐字输出** | ① 本地服务请求头加 `X-DashScope-SSE: enable`、`parameters` 加 `incremental_output: true`，把 `upstream.body` 直接 `pipe` 给浏览器；② 前端用 `fetch` + `ReadableStream` 读取 `data:` 行并追加渲染 |
| **临时 Key 模式** | 本地服务用永久 Key 调 `POST /api/v1/tokens?expire_in_seconds=1800` 换 `st-` 临时 token，再下发给前端 |
| **换成 Responses API** | 端点改为 `POST https://dashscope.aliyuncs.com/api/v2/apps/agent/{APP_ID}/compatible-mode/v1/responses`，请求体用 OpenAI 风格的 `input` |
| **换用官方 SDK** | 改为 Python（`pip install -U dashscope` 后用 `Application.call`）写本地代理，逻辑完全一致 |

## 4. 要构建一个"可运行"的示例，你还需要做的准备

### 4.1 阿里云侧（必须先完成，否则代码写得再对也跑不通）

- [ ] **阿里云账号已完成实名认证**，且已**开通百炼服务**（首次进控制台同意服务协议）。
- [ ] **确认目标智能体应用**：
  - 在[应用管理](https://bailian.console.aliyun.com/?tab=app#/app-center)打开你创建的智能体，**记下应用 ID（APP_ID）**（应用卡片上可复制）；
  - **确认已点过"发布"**——`APP_ID` 调用的是"最新已发布版本"，只在草稿里看到的配置不会被 API 使用；
  - 最好先在控制台里用对话框走通一次问答，确认应用本身能正常回复。
- [ ] **创建并记录 API Key**：在[密钥管理](https://bailian.console.aliyun.com/?tab=model#/api-key)创建，形如 `sk-xxxxxx`；注意 **Key 与地域绑定**（本示例用默认的华北2（北京）端点即可）。
- [ ] **确认计费与额度**：核对所用模型的免费额度/单价，避免测试时超支（见控制台"模型广场"模型卡片的额度说明）。
- [ ] （可选）确认是否需要调用**子业务空间**的应用——若是，调用时需额外携带 `X-DashScope-WorkSpace` 请求头。

### 4.2 本地环境侧

- [ ] **安装 Node.js ≥ 18**（本示例用内置 `fetch`，无需 npm 安装任何依赖）；装好后验证：
  
  ```powershell
  node -v      # 应输出 v18 或更高
  ```
- [ ] 本机 **3000 端口未被占用**（被占用时改 `server.mjs` 里的 `PORT`）。
- [ ] 网络能正常访问 `https://dashscope.aliyuncs.com`（可在 PowerShell 里先用一条 curl 验证连通性）。
- [ ] **密钥安全**：确认密钥只存在于环境变量/本地文件中，**不要提交到 Git**（本工作区是 Git 仓库，如创建 `.env` 类文件务必先加进 `.gitignore`）。

### 4.3 交给 AI 执行前，需要你提供/确认的信息

1. `DASHSCOPE_API_KEY` 的存放方式（推荐：你自己在终端设置环境变量，不要直接贴进对话/代码）；
2. `APP_ID`；
3. 应用类型是 **Agent 2.0 还是 Agent 1.0**，以及是否需要**多轮对话**、是否需要**流式输出**；
4. 前端是否要求无框架纯 HTML（课程一般如此）。

## 5. 常见问题排查表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 浏览器控制台报 CORS 错误（`blocked by CORS policy`） | 网页在直连百炼，或被本地服务拦截 | 确认网页只请求 `http://localhost:3000/api/chat`，不直连 `dashscope.aliyuncs.com`；本地服务本身不需要给百炼发跨域头 |
| 401 / `invalid_api_key` | Key 写错；或 **Key 与端点地域不匹配** | 检查 `sk-` 值；确认用的是对应地域控制台创建的 Key |
| 403 / `Model.AccessDenied` | 模型未开通/无权限 | 在控制台开通对应模型服务 |
| 返回成功但回答内容不是最新配置 | **应用修改后未发布** | 控制台点"发布"后再试 |
| 多轮对话"失忆" | `session_id` 超过 **1 小时无请求**已失效；或前端没回传 | 前端保存并回传 `output.session_id`；或改用自维护 `messages` 方案 |
| 调用超时 / 长回答等待久 | 非流式长文本生成 | 改用流式（`X-DashScope-SSE: enable`） |
| 429（限流） | 请求频率/额度限制 | 降低频率，稍后重试；核对额度 |
| 一切正常但报错难懂 | —— | 记下响应里的 `request_id`，查[错误码文档](https://help.aliyun.com/zh/model-studio/developer-reference/error-code)或提交工单 |

**排错顺序建议**：先用控制台"应用卡片 → 发布 → API 调试"确认应用侧可用 → 再用 curl 直接打 API 确认凭证可用 → 最后才排查网页/代理代码。
