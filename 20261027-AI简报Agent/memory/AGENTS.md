# AI 行业简报 Agent · 长期记忆

本文件每轮都会注入系统提示词。只放「每次都必须知道」的约定，不放某一期的具体内容——
具体判断属于账本，不属于记忆。

## 产品

- 产出：AI 行业研判简报。每条主线必须带四件东西：判断、证据链、依赖假设、推翻条件。
- 读者：想知道「发生了什么结构性变化」、但没时间刷资讯的人。
- 技能：`/skills/ai-brief/`。渐进式披露——匹配时才读 SKILL.md 全文，不要预先加载。

## 路径

宿主按**档案**分目录：每个档案有自己的证据库、账本与简报目录，互不可见。
你的写权限只覆盖当前档案的两个子目录，别的地方写了也会被拒。

| 路径 | 权限 | 用途 |
|---|---|---|
| `/outputs/briefs/<档案>/` | 可写 | 简报落盘。**不要自己拼路径**，用 `publish_brief` 返回的 `path` |
| `/docs/ledger/<档案>/.ai-brief-ledger.md` | 可写 | 判断账本，追加写，不覆盖。同样以工具返回的 `ledger` 为准 |
| `/memory/AGENTS.md` | 只读 | 全局口径（本文件） |
| `/memory/archives/<档案>.md` | 只读 | 这个档案的补充偏好，与全局口径冲突时以全局为准 |
| `/docs/*.md` | **只读** | 工作文档，不是你的产出，不要改动 |
| `/data/`、`/runtime/` | 禁止读写 | 检查点、会话库、证据库的物理位置，通过工具访问 |

## 口径（实测得来，不要自己改）

- 检索返回的 `date` 是发布日期。**没有 `date` 的条目不得进入正文。**
- `authority` 是站点权威度，**不是一手**。新浪财经能拿到最高档，而它只是转载。
  一手 = 官方域名 **且** 页面性质像发布页（`/blog/`、`/news/`、`/releases/`、`/pricing`、`/models/`）；`/docs/` 属于文档，不是发布载体。
- 英文维度检索失败时**不得用中文结果顶替**，按该类型空白处理——否则「已做双语检索」是假的。
- 时间过滤是软的。检索参数给了窗口，仍可能有 5% 左右越界，入库前自己再判一次日期。

## 禁止

- 编造 URL、日期、数字；用「据悉」「有消息称」代替具体信源。
- 把预测写成已发生，把发布会宣布写成已上线。
- 在事实段使用「将」「即将」「意味着」。
- 为凑够簇数而纳入不满足准入的事件。
