  设置 `HF_HUB_OFFLINE=1` / `TRANSFORMERS_OFFLINE=1`。已跑通。

### qwen2.py（Streamlit 对话界面）
原示例代码的 5 个问题（已全部修正）：
1. `generate_response()` 每次只传单条 user 消息 → 多轮历史被丢弃（界面记录是摆设）。
   修正：把完整 history 交给 apply_chat_template。
2. `max_new_tokens=65536` 远超上下文上限 40960 → 触长度上限、白跑几十分钟。
   修正：改为 1024，并加截断保护（超长时从左侧截断到 39936）。
3. 假流式：先一次性 generate 完，再 split() 逐词"打字机"。
   修正：用 TextIteratorStreamer + Thread 真流式。
4. 助手回复在生成**之后**才写入 session_state，生成期间若会话重跑会丢失用户输入。
   修正：用户消息先生效、助手消息生成完立即落盘。
5. 缺 model.eval()、无不采样说明。

验证结果（实测）：多轮历史生效（prompt 长度 14 → 39）、真流式（214 个片段）、
截断保护生效（30009 → 39936 以内）。
