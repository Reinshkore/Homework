# 上海杉达学院「开源技术创新应用」微专业 · 宣传要点

## 一、一句话定位

**上海杉达学院「开源技术创新应用」微专业** —— 依托开放原子开源基金会"1+4+X"课程体系，深度对接华为国产开源生态，聚焦国产开源与人工智能产业人才需求。完成学业可获**校内官方结业证书**，并可考取**华为系列官方开发者认证**。

---

## 二、核心卖点

### 1. 全国首创，起步最早
- 开放原子"校源行"**首批合作高校**
- **全国首创**"开源技术创新应用"微专业，历经多轮迭代
- 报名人数居全校各类微专业**首位**
- 跨学科招生，覆盖**护理、金融、艺术、工程**等多专业

### 2. 国家级认可
- 入选**应用型高校产教融合微专业建设项目库**，荣获**一等奖**（全国数百所高校同台评审）
- 作为一等奖优秀代表受邀在全国论坛作主题报告
- **上海民办本科唯一**入选《2025 中国高校开源育人案例集》，与清华、北大、上交、复旦、北航等同列
- 入选**工信部根技术联合创新人才产教融合基地**

### 3. 硬核战绩

| 指标 | 数据 |
|---|---|
| 开源相关课程 | **20 余门**（融入 OpenHarmony / openEuler 等根技术） |
| 参与教师 | **33 名**通过华为、沐曦等企业认证 |
| 学生参与开源社区贡献 | **1200 余名** |
| 孵化鸿蒙原生应用项目 | **123 项** |
| 国家计算机软件著作权 | **14 项** |
| 实现商业化落地 | **6 个** |
| 自研鸿蒙 APP 上架华为应用市场 | **86 款** |
| 学生获华为技术认证 | **近 300 人次** |

### 4. 真项目、真企业
- 合作方：**华为、开放原子开源基金会、AtomGit 平台、沐曦、麒麟、武创大智**等
- 打通华为云、鲲鹏、昇腾、鸿蒙全线资源
- 学生全程依托**开放原子官方开源项目 + 华为真实商用项目**实训
- 共建**"教学 — 实践 — 就业"一体化开源基地**

### 5. 证书与出口
- 可考取：**华为云微认证、鸿蒙开发者认证、华为职业认证**等
- **结业推荐至华为生态企业就业**，方向覆盖 AI、大数据、云计算、物联网
- 支持**学分置换**，可抵扣公选课与跨专业选修课学分

### 6. "六源共育"育人体系
- 完整链路：**课堂学习 → 开源贡献 → 项目研发 → 商业化落地**
- 配套：校内**开源社团**、**上海首家高校开源双语头马俱乐部**、**全国首家开源创新实践基地**
- 理念：**生态共建、项目牵引、AI 融合**
- 路径：**早启蒙、深融合、强落地、高适配**

---

## 三、课程体系（"1+4+X"）

**五大模块**：开源文化 / 知识产权合规 / 社区治理 / 商业化落地 / AI 大模型融合

| 模块 | 课程 |
|---|---|
| 源文化 | 《开源文化导论》 |
| 源技能 | 《低代码开发项目实践》→《GIT 分布式代码版本控制》→《OpenHarmony 软硬协同创新实践》→《开源大模型智能系统设计》 |
| 源规律 / 战略 | 《开源社区管理与组织》《开源商业模式分析》《知识产权和开源许可合规》 |
| 综合实践 | 项目式教学，参与开源与 AI 融合的真实项目 |

> 宣传口径核心课程：**开源创新思维、智能终端软硬协同开发、知识产权和开源许可合规**

---

## 四、荣誉与战绩

**荣誉**
- 入选**2025 中国高校开源育人案例**（上海民办本科唯一）
- 开源社团获开放原子**"星火团"**称号
- 获**上海开源创新卓越成果奖**二等奖
- 获 **OpenKylin 高校站**授牌
- 成立**全国首家开源创新实践基地**
- 应用型高校产教融合微专业建设项目库**一等奖**

**学生竞赛**
- **AI + 互动游戏挑战赛全国二等奖**（开放原子基金会 × 阿里魔搭 ModelScope 主办，全国 480 余支高校团队参赛）
- **"我的云主机，我做主"HCDG 创意设计大赛**（联合华为举办，基于华为云开发者空间，使用 MaxKB、DataEase、Halo、1Panel 等开源工具完成作品）
- 全国大学生信息安全与对抗技术竞赛**全国一等奖**
- 华为 ICT 大赛等国家级、市级赛事屡获大奖

## 五、招生要点

- 面向全校**大二、大三（含专升本）**全日制在校本科生
- **不限专业**
- 12 学分 / 1 学年

---

## 六、学校背景

- 2024 年获批**电子信息硕士学位授权点**
- 上海市首批现代产业学院——**现代智慧服务产业学院**
- 创新实施 **"1+M+N"三维融合人才培养模式**
- 2025 年获批上海高等学校一流本科课程：**操作系统**
- 开放原子开源社团理念：**开源共享，融合创新**
